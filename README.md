# WEB-BASED QUIZ (Mini-Project)

## About:

This is a web-based quiz mini-project with concepts applied on my previous lessons in JavaScript.

## Concepts Used:

1. Objects
2. DOM Manipulation (Event Handling)
3. Arrays
4. Loops
5. Selections
6. Web Components
7. Functions
