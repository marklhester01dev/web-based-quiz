# FEATURES

1. Progress indicator during the quiz
2. Multiple quiz categories to choose from
3. Local storage for saving quiz data (no database)
4. Automatic scoring based on user answers
5. Quiz result generation at the end of the quiz
6. Score viewing after the quiz is completed
7. Correct answers shown after the quiz
8. XSS injection prevention (input sanitization/validation)
9. Responsive design for different screen sizes
