# Project Deliverables

- Functional quiz web app covering all Functional Requirements (FR1-FR8)
- Responsive layout across screen sizes (NFR5)
- Accessible to screen readers, particularly NVDA (NFR3)
- CSP `<meta>` tag and input sanitization in place (NFR4)
- Verified on Chrome, Firefox, Edge, and Safari (NFR2)
- No backend/database - all data persisted via `localStorage` only (FR7)

## 2. Source Control

- All code and documentation committed to the project's Git repository
- Commit history reflects incremental development (one meaningful change per commit, per the workflow established during this project)
- Final version pushed to the designated branch

## Out of Scope (not deliverables)

Per `scope.md`'s Limitations, the following are explicitly **not** part of this project's
deliverables and should not be expected in the final submission:

- Quiz creation/editing tools (questions are fixed/hardcoded)
- A database or server-side component
- User login/signup
- Advanced statistics (streaks, leaderboards)
- Deployment or hosting
