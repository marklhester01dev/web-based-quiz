# OBJECTIVES

## General Objective

1. Develop a web-based quiz system (no database, using local storage) to apply the HTML, CSS, and JavaScript skills learned over the past months.

## Specific Objectives

1. Allow users to select a quiz category before starting.
2. Track and display the user's progress during the quiz.
3. Generate and display quiz results, including the user's final score.
4. Show the correct answers after the quiz is completed.
5. Ensure the interface is responsive and adapts to different screen sizes.
6. Sanitize and validate all user input to prevent XSS injection.
