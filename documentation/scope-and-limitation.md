# SCOPE

1. Quiz taking with multiple categories to choose from
2. Progress indicator shown during the quiz
3. Quiz results generated at the end of the quiz
4. Correct answers shown after the quiz
5. XSS injection prevention (input sanitization/validation)
6. Responsive design for different screen sizes

# LIMITATIONS

1. No quiz creation or editing feature (questions are fixed/hardcoded)
2. No database (data is stored using local storage only)
3. No user login or signup
4. No advanced quiz statistics (e.g., streaks, leaderboards)
5. Fixed number of questions per category
6. No deployment or hosting
